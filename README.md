# ديوانية — منصة الألعاب الجماعية

27 لعبة تعمل فعلياً، بغرف مباشرة يدخلها كل لاعب من جهازه برمز أو رابط.

## التشغيل على جهازك

يحتاج Node.js 18 أو أحدث فقط. لا توجد أي مكتبات للتثبيت ولا مفاتيح API ولا قاعدة بيانات.

```
node server.js
```

ثم افتح `http://localhost:3000`. من على الشبكة نفسها (واي فاي البيت) يدخلون عبر عنوان جهازك، مثل `http://192.168.1.20:3000`.

## النشر برابط عام (ليلعب الأهل والأصدقاء من أي مكان)

المشروع خادم Node واحد، فيعمل على أي استضافة تشغّل Node. مثال Render (فيه خطة مجانية):

1. ارفع هذا المجلد إلى مستودع GitHub.
2. في Render: New ← Web Service ← اختر المستودع.
3. Build Command: اتركه فارغاً (أو `npm install`) — Start Command: `npm start` — Instance Type: Free.
4. بعد النشر تحصل على رابط مثل `https://diwaniya.onrender.com`. هذا هو الرابط الذي ترسله للجميع.

ملاحظات على الخطة المجانية في Render: الخدمة تنام بعد 15 دقيقة بلا زيارات، وأول فتح بعدها يأخذ نحو دقيقة. الغرف محفوظة في ذاكرة الخادم، فتُمسح عند نومه أو إعادة تشغيله. للعب المتواصل لا مشكلة، لأن الخدمة لا تنام ما دام هناك لاعبون.

## كيف تعمل المزامنة

- `server.js`: يحفظ آخر حالة لكل غرفة ويوصلها للاعبين عبر SSE، ويستقبل أفعالهم عبر POST. لا يعرف قواعد أي لعبة.
- قائد الغرفة يشغّل منطق اللعبة في متصفحه ويبث الحالة. إذا انقطع أكثر من 12 ثانية ينقل الخادم القيادة تلقائياً للاعب متصل وتستمر المباراة.
- أي لاعب يحدّث الصفحة أو ينقطع يعود إلى مقعده تلقائياً (هويته محفوظة في متصفحه).

## إضافة لعبة جديدة

أنشئ ملفاً في `public/js/` وسجّل اللعبة بـ `G.reg({...})` ثم أضف وسم `<script>` في `index.html`. الحقول:
`id, n, cat, em, hue, min, max, t, modes, d, r, opts` والدوال `init(ps,o,H)`, `act(st,p,a,H)`, `tick(st,H)`, `view(st,me,H)`, `bot(st,p,H)`.
لا تعديل على الخادم ولا على `app.js`. شغّل `npm test` لتُلعب اللعبة الجديدة آلياً مئات المرات.

## الاختبارات

- `node test/perft.js` — يتحقق من قواعد الشطرنج مقابل أعداد النقلات المرجعية.
- `node test/fuzz.js` — يلعب كل لعبة حتى نهايتها بلاعبين آليين (بأقل وأكثر عدد لاعبين) مع أفعال عشوائية خاطئة.
- `node test/e2e.js` — ثلاثة متصفحات حقيقية على الخادم: انضمام، دردشة، تصويت، مباراة كاملة، رسم وتخمين، إعادة اتصال، انتقال القيادة (يحتاج Playwright و Chrome).

## حدود معروفة

- الملف الشخصي والعملات والإنجازات محفوظة على جهاز اللاعب فقط (لا حسابات ولا لوحة ترتيب عالمية).
- حالة اللعبة كاملة تُرسل لكل المتصفحات، فيمكن لمن يفتح أدوات المطوّر أن يرى الأدوار السرية. مناسب للعب بين الأصدقاء لا للمنافسات الجادة.
- لا توجد محادثة صوتية؛ ألعاب النقاش (الجاسوس، المافيا) تفترض مكالمة جانبية أو الدردشة النصية.
